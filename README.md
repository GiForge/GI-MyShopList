# 🛒 Smart Shopping List

Una lista della spesa intelligente per Android con **riconoscimento vocale in linguaggio naturale**, gestione del budget in tempo reale, organizzazione per categorie e condivisione immediata delle liste.

✅ Comandi vocali in italiano  
✅ Budget e carrello in tempo reale  
✅ Ricerca immagini Google  
✅ Gestione categorie personalizzate  
✅ Database locale Room SQLite  
✅ Condivisione rapida WhatsApp
